# НВП для детских лагерей

Статический сайт-визитка выездной программы начальной военной подготовки для детских лагерей.

## Структура

- `dist/index.html` — страница сайта;
- `dist/styles.css` — визуальные стили и адаптивная вёрстка;
- `dist/app.js` — мобильное меню и анимации;
- `dist/assets/` — логотип, карта и фотографии реальных смен.

## Локальный запуск

Сайт не требует сборки. Достаточно запустить любой статический HTTP-сервер в папке `dist`.

```bash
python3 -m http.server 4173 --directory dist
```
