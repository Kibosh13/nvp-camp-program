# НВП для детских лагерей

Сайт-визитка с защищённой панелью управления контентом.

## Что редактируется

- SEO-заголовок, описание и индексация;
- все тексты, подписи и пункты навигации;
- логотип, фотографии карточек, сотрудников и галерей;
- подложка карты;
- точки на карте: добавление, удаление, координаты, перетаскивание и логотип лагеря.

Изменения сохраняются в Cloudflare D1, загруженные изображения — в R2. Доступ к `/admin` защищён входом через ChatGPT и политикой доступа Sites.

## Локальная разработка

```bash
npm run dev -- --port 4173 --hostname 127.0.0.1
```

Для локального входа откройте `/signin-with-chatgpt?return_to=/admin`. После первой сборки примените миграцию:

```bash
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_whole_scream.sql
```

## Сборка

```bash
npm run build
```

`static-demo/` содержит автономную статическую версию для GitHub Pages. Она закрыта от поисковой индексации и не использует серверную CRM.
